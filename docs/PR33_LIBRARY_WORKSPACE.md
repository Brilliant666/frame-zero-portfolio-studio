# 本站图库、图集库与精确排序

2026-09-29，承接用户对 3003 图集管理的实际体验反馈。前版 1103px 视口下照片卡片单列、每张约317px高，预览占约430px；不适合几十张图集排序。

## 本次行为

- 高级后台新增图集库和本站图库。图集库展示封面、名称、数量和显示状态；本站图库独立上传、筛选、48张分页、跨页选择并加入明确的高级图集。
- 本站图库切换分区保留尚未加入的选择。加入仍复用原append校验：去重、成员上限、请求体大小、资源有效性；不会保存或发布。
- 图集内部默认全宽照片排序，紧凑缩略图、序号、选择和拖动手柄。封面/移出在图集设置统一操作。
- 多选移动支持最终起始序号、指定照片前/后；选中照片保持原有相对顺序。第47张移到第3位无需跨屏拖动。
- 单张拖动显示前后插入线，保留键盘移动和取消。撤销最近移动仅在集合对象及成员顺序仍匹配时可用，不覆盖外部新编辑。
- 展示效果独立页签读取当前内存草稿，保留构图模式；返回排序保留选择和滚动位置。可主动开启上下对照。

基础/高级业务内容仍独立，Site素材共享；保存、发布、权限和公开白名单不变。没有数据迁移、资源删除、账号或上传底层重构。
