# 首页 → 图集进场：本机正式构建验收

本轮仅调整新版进场及其本机测量工具；不调整构图、主题、套餐或联系页。原版首页、后台、十一模板和保存契约保持不变。参考 HTML 只读，通过浏览器测试注入同一组 11 张实图；未修改参考文件或私人图库。

## 验收对照

1. **通过：保留首页退场。** 点击帧建立封面替身并隐藏原封面；标题上浮，其他封面下落淡出。图集在下层挂载，首页等退出动画完成再卸载。标题、文案、封面分别采用 520/380/460ms 动画及短交错延迟。
2. **通过：代码预热，无进入占位。** 首页空闲时预加载场景，悬停、聚焦、按下补充预热。预加载完成后直接渲染已解析组件，避开 React.lazy 首次 Suspense 的额外等待；进入不显示加载占位。
3. **通过：照片准备。** 预热包括落点封面，等待 decode，点击起最多等待 300ms；未就绪照片解码后 200ms 淡入。默认 600px 内存缩略图，缩放后按显示需求升级至 1100/2200px；失败或乱序请求不替换已显示的更高清照片。
4. **通过：单一飞行替身。** 只创建相纸容器及封面图片，不克隆卡片、不遍历复制计算样式。统一等比 scale，落点读取实际相纸内边距，落地后 180ms 淡出。落点保持同一张封面且无透明度或显影动画。
5. **通过：可见照片钉入。** 仅视口相交卡片按可见位置排序；延迟期透明，随后从上方 46px、额外 7° 旋转钉入，纸面使用轻回弹曲线。屏幕外卡片直接到位。减少动态效果关闭位移动画；照片仍需正常完成加载。
6. **通过：本机正式构建与对比证据。** 独立构建目录 `.next-local-preview`，本机环回 runner 使用每次启动随机证明，普通生产构建仍关闭 `/preview`。隔离浏览器 API 夹具，不连接 D1，不读写记录 2601。构建预算未调整。

## 本机证据

证据目录：本机 Codex artifacts 下的 `collection-entry-real/`（不进 Git）。

- `comparison.html`：修改前开发版、同组实图样张、新版正式构建同步播放；支持 50ms 时间滑块。
- `window-stats.json`：点击后 0–1500ms 的 Chrome trace 帧统计。
- `photo-timing-report.md`：逐照片请求完成时间、字节数。
- `per-photo-decode.md`：逐照片解码与可见时间。
- `edges.json`：减少动态效果、封面不在首屏、延迟照片验证。
- `responsive.json`：1440×900、1280×720、390×844、320×720 代表截图。

测量口径为 `DroppedFrame / (DrawFrame + DroppedFrame)`，不是固定 60Hz 推算。独立 headless Chrome 的实际采样为高刷新节奏，录屏和 trace 均有开销。修改前是开发构建，因此前后差异不能全归因于代码；样张与新版使用相同 600px 图片输入。

### 最终 v4 测量

| 场景 | 0–1.5s 掉帧率 | 点击至替身出现 | 点击至正式飞行 |
| --- | ---: | ---: | ---: |
| 修改前开发版（1100px） | 10.43% | — | — |
| 同组实图 HTML 样张（600px） | 18.92% | — | — |
| 本机正式构建，未悬停预热 | 7.01%（34/485） | 1.7ms | 63.6ms |
| 本机正式构建，悬停预热 | 7.79%（38/488） | 0.8ms | 40.7ms |

**未通过此前的 5% 性能目标。** 单次高刷新采样存在波动，不能据此声称预热必然降低掉帧率。这里“冷”表示未悬停预热的浏览器场景，不表示操作系统或本机缩略图服务缓存已清空。首页保留约 552–553ms 后卸载；落点卡片及照片 opacity 最低为 1，filter 始终为 none，加载占位出现次数为 0。

未预热场景：封面在点击前约 4008ms 已完成下载；其余十张在点击后 27.7、28.1、32.2、32.4、32.8、40.4、40.7、41.2、41.3、42.2ms 完成下载，最后一张在 62.6ms 完成 decode。逐图对应关系在本机时间报告中保留，不将私人素材标识写入仓库。

取消验证 **通过**：进入后约 100ms / 650ms 分别切换套餐与联系，共四组；无飞行残影、残留动画或可见图集。证据：`cancel-v4.json` 及对应截图。
