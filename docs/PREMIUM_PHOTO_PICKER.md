# 高级图集批量选片

范围：高级拍立得后台的本站选片流程。基础模板的业务内容、保存版本和排版界面保持独立。

## 用户流程

1. 图集管理中选择目标图集，打开「从本站图库选片」。上传仍使用原本站上传入口。
2. 按方向、是否已加入本图集、加入本站时间筛选浏览；可用素材 ID 检索。每页 48 张。
3. 跨页选择或选择本页可加入照片。「查看已选」显示全部暂选项，并按选中顺序排列，不受之前筛选影响。
4. 确认加入后，新成员按选择次序追加，原成员顺序保留。取消选片不改变图集。
5. 在成员网格检查顺序，通过上下移动或「移到第…位」调整，然后显式保存修改。

选择、加入内存草稿、保存草稿是三个不同状态。此流程不发布，也不移动 Published 指针。
暂选绑定当前图集；原生模态面板打开时不能切换背景中的目标图集。关闭后暂选清空。

## 数据与限制

- 复用 Site Asset API、上传、归属校验和高级草稿 CAS。无数据库 schema 变更或迁移。
- `createdAt` 来自已有 `site_assets.created_at`，只表示加入本站时间，不表示拍摄时间或原始上传批次。同时间按 ID 稳定排序，未知时间排末尾。
- 未保存文件名、名称、EXIF 或批次，界面不提供这些搜索承诺。
- API 探测第 10001 条并返回 `truncated`。超过 10000 条时明确提示仅载入部分素材；前端分页不是服务端全库分页。
- 加入时按最新草稿重新去重，验证资源仍在已载入列表中、目标仍存在、每图集最多 500 张及完整保存请求最多 512000 字节。超限整批拒绝，不截断。
- 图库刷新失败保留原成员和暂选，禁用加入；重试成功后重新核对。过时响应不能覆盖较新的加载结果。
- 保存继续使用原有版本冲突处理和服务端资源归属检查。保存成功不依赖再次读取素材。
- 图片放大与选片使用模态键盘范围，关闭恢复焦点。移出仅解除图集成员引用，不删除资源或独立封面。
