## 操作路径与验证

1. 高级图集 → 本站图库 → 第一页选一张 → 第二页选一张 → 查看暂选顺序 → 加入图集 → 仅保存草稿。真实 API 回读确认严格按选择顺序追加两张，基础草稿和 Published 不变。
2. 成员照片 → 看大图 → Ctrl/Cmd+S → Escape。未误保存，关闭后焦点回到原照片按钮；显式保存后高级版本递增，再显式发布成功。
3. 基础 → 更多 → 兼容内容与工具，原路由可达；模板页不再使用“当前主页模板”描述草稿模板。可选联系卡打开选片后取消，不产生未保存修改。
4. 手机弹窗和预览开启时底部按钮隐藏且 inert，关闭恢复。320、390、768、1280、1440 已核对，无横向溢出。真实手机系统软键盘尚待人工验收，桌面改视口不冒充此验证。
5. 基础跨空间“保存并发布”触发原确认框后，浏览器控制持续超时；后端回读确认未发生该次保存或发布。此浏览器路径与冲突恢复 UI 的追加实测未完成，不计通过。既有逻辑未改，隔离 API 的基础／高级保存、409 CAS、准确版本发布已通过。
6. `/test` 只核对现有 origin/验收配置差异：日常匿名管理入口回登录，候选按既有本地预览配置进入模板。没有放宽 Host、origin、Cookie、CSRF 或授权检查。
