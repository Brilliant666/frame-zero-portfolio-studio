## 4. Geist：原因查明，按要求不修设置

详见 `GEIST_DEV_FONT_DIAGNOSIS.md`：vinext Windows 路径分隔符不一致使磁盘地址漏到 CSS。正式 Next standalone 的 11 个字体 URL 均同源且 HTTP 200。开发报错保留，未修改字体配置或依赖；legacy vinext 构建不在“已确认正常”的结论内。

## 5. 文字加载提示：通过

之前来自 API 读取和多层 React Suspense 的普通文字占位，早于开场动画加载。现统一为同风格星标与 00 等待态，资源就绪后进入首次开场。等待阶段不伪造网络加载百分比；开场 00–100 仍是动画进度。返回及同标签刷新不重播首次动画的规则保持。

延迟 API 一秒时无旧提示闪现；模拟 503 时显示可读错误且遮罩移除。没有使用动画隐藏错误或永久等待。
