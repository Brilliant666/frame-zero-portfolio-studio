# Site 后台布局第一轮

日期：2026-09-28。基线：main `20d87433eb140f3d48ecec5fa175f0d72895ee53`。
用户在后台只读审查后授权“按照你的建议开始修改”。

## 本轮修改

- 基础版保留六个分区和现有编辑组件，吸顶栏集中展示当前分区、保存状态、保存按钮；空间切换与草稿预览移入次级区域。
- 高级拍立得拆成图集管理、主页资料、拍摄套餐、联系约拍四个分区，支持分区 hash 定位；保持一份独立高级草稿，不自动同步基础资料。
- 图集成员由长条列表改为可看图的网格，保留顺序与移出操作；封面/焦点等低频设置折叠，避免把照片推到页面底部。
- 保存常驻顶栏；未保存编辑的内存预览、已保存草稿预览和公开主页使用不同名称。导出和重新读取放入“更多操作”。
- 发布区域以草稿/公开版本和同步状态为主，历史、回退及刷新折叠；原确认、版本检查和授权逻辑不变。
- 两套 Site 后台统一浅灰工作区、白色卡片、蓝灰操作色与圆角；旧兼容编辑器与公开模板不套用 Site 样式。

## 验证与保护

- Standard Next 正式构建、TypeScript、定向 ESLint、37 项后台相关单元测试通过。
- 本机隔离 PostgreSQL + Chrome：27 项集成测试通过，其中真实编辑器 12 阶段、素材 6 阶段。包含双空间独立性、保存中继续编辑、冲突、预览、重启持久化和跨站拒绝。
- 浏览器测试允许通过 `FRAME_ZERO_BROWSER_CHANNEL=chrome` 复用本机已安装 Chrome；未设置时 CI 仍使用 Playwright 默认 Chromium。最初默认浏览器运行因本机缺少对应版本而未启动，不算产品通过证据。
- 有界面独立 Chrome 对 star 后台进行 1440/390/320 宽度只读检查；不使用用户的浏览器配置，不提交保存/发布请求。草稿与发布接口前后完全相同。
- 本地证据位于 `%LOCALAPPDATA%/PortfolioPlatform/local-m3/admin-layout/`；截图含用户照片，不提交公共仓库。
- 数据保护验证：9 张业务表、135 个私有素材文件、137 个旧图库文件、4 个平台卡与收口基线匹配。SQLite、私人图库、账号环境文件不改动。
- 构建体积继续使用现行政策：结构性门禁通过，跨路由 CSS 微小增长作为 warning 审查，不为字节数改产品或提高硬限制。

## 边界和验收入口

新版候选使用本地 3003；日常 3001 仍为已接受 main。本轮不自动合并、不切换日常版本、不部署。

这是一轮布局与操作层级整理，不宣称后台所有体验问题已解决。基础版的模板槽位工作流保持现状，批量素材整理和新增分享卡上传能力不属于本轮。

人工可重点检查：高级四分区切换、图集照片网格、封面设置展开、手机保存常驻，以及“保存草稿”和“发布”的区别是否清晰。
