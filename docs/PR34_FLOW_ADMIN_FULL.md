## 保存、预览与恢复

- “仅保存草稿”和 Ctrl/Cmd+S 仍只保存独立草稿；“保存并发布”沿用准确草稿回执及 Published 指针的版本检查。
- 草稿身份与当前公开身份同时显示。切模块、创建分类、选片、查看当前编辑效果均不会隐式保存或发布。
- 普通预览、导出、重新读取和发布历史集中在“预览与草稿工具”；共享 `PublicationControls` 新增可选外观参数，仅 Flow 启用，其他后台保持默认界面。
- 草稿冲突、读取失败和结果待核对的导出／核对入口直接显示；发布异常展开工具，反馈与只读刷新始终可达。没有把异常恢复藏进低频工具。
- 手机保留固定双保存按钮；命名、选片和效果弹窗打开时，后台保存栏不可交互。原软键盘感知、焦点、hash 返回及预览滚动锁保留。
- Flow 对共享排序器保留其返回对象，修复适配时重新创建对象导致撤销失效的问题；外部成员、元信息或顺序变化仍使旧撤销失效。
