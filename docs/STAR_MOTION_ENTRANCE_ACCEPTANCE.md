# 两种入场与图集左侧信息卡

分支：`codex/star-motion-preview`。本轮只补主页首次开场、进入图集动画及返回/标题排版；不扩展 D0、数据模型、后台或部署。

## 基线与隔离

基线 `5e6b140` 中主页只有普通 CSS 淡入，缺少首次进度、跳过与逐字标题；图集缺少封面飞行和显影；返回按钮与标题为分离的两块。基线认定来自源码及用户截图，不冒充新拍的修改前截图。

浏览器使用独立 Chrome 上下文，全部 API、图库清单和图片请求在导航前拦截为合成夹具。没有读取或写入真实 2601，也未复制、提交或上传 `public/photos`。录像、截图和脚本仅保存在本机 `$CODEX_HOME/artifacts/star-motion-entrance/`。

## 逐项验收

| 项目 | 结果与证据 |
| --- | --- |
| 首次开场 | 通过：950ms 星标/00–100 开场进度、放大淡出、标题逐字升起及末尾星光；`home-check.json`、`home-intro-progress.png`。进度不是网络加载进度。 |
| 首次与跳过语义 | 通过：同标签会话只播一次，刷新/图集返回/深链返回不重播；点击、Enter、Esc 跳过，焦点回到图集操作；存储不可用安全降级。`home-check.json`、`home-extra.json`、`home-intro.test.mjs`。 |
| 图集入场 | 通过：封面 980ms 飞入、160ms 交接，其余相纸按保存顺序 60ms 错峰/760ms 落定、1700ms 显影、星钉与线条依次显现。`collection-entrance.test.mjs`、桌面录屏与 `entry-check.json`。 |
| 返回与标题排版 | 通过：同一张卡中先返回、再标题和说明；桌面左右信息区分开，手机自然堆叠。`header-1440.png`、`header-1280.png`、`mobile-collection.png`。 |
| 减少动态效果/清理 | 通过：减少动态效果立即到位；快速交互、离开图集、卸载取消飞行浮层及动画；`home-extra.json`、入口单测和 reduced 录屏。 |
| 夜空 | 通过：独立 canvas，桌面 140–460 粒子、手机半量，仅夜空绘制，减少动态效果静态显示；两种入口触发短促加速。`sky-check.json` 实测桌面 309、手机 70 粒子，模拟 visibilitychange 暂停检查通过（不是操作系统切换标签的录屏证据）。 |

手机保存主角在屏下时，动画落点使用首屏可见相纸，不更改保存主角、编号、排序或自动滚到屏下。源封面不在屏幕中时不伪造飞行，直接相纸入场。
