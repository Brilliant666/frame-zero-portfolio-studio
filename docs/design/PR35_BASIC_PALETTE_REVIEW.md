## 1. 结论

十一套全部纳入检查，不再将五套中文排版修复等同于整套视觉完成。
当前最明确的调整项是 cinematic-light 的首屏明暗衔接、film-rail 的整条深色片基，以及冷色浅模板进入共享米黄灯箱时的色温跳变。其余模板不为凑数量而改版。

基础模板目前是**每套固定一种主基调**，不是十一套均提供可切换的亮／暗模式。
`app/templates/appearance.ts:5-15` 定义八套浅色、三套深色。统一是让同一模板的各模块协调，不是让十一套使用同一底色。

## 4. 推荐实施切片（尚未实施）

### A：电影首屏与胶片轨道

1. Cinematic 保持暖白主调。先做局部暖白文字承载渐变和深色文字／操作的候选，照片中心保持原样；减少全屏重黑罩与浅导航的突变。若复杂照片下对比不足，调整文字背后的局部承载层，不统一提亮照片、取消照片或新增大块固定栏。
2. Film 的片基主体采用暖灰／浅棕，与纸面同色系；图注改深墨色。深色保留在窄胶片边与少量标识，齿孔、帧号和横向浏览不变。具体明度需同图对照，方案不是直接批准某个颜色值。
3. 不改排版尺寸、文字、照片裁切、槽位、顺序或交互逻辑；需要改变上述内容时另列原因与范围。

### B：基础灯箱和共享联系卡的材质衔接

1. 沿用现有 light／dark 行为，只提供模板局部底色、边线、文字与强调色变量；不建设主题引擎或新增设置项。
2. 棱镜采用冷白紫灰，档案采用中性浅灰，电影／胶片／杂志／基础拍立得保持各自暖纸，展厅采用中性暖灰。深色模板保持各自暗色体系。
3. 平台联系卡已有 tone 支持。仅在实际对照显示砖红／珊瑚默认强调与模板不协调时调局部变量；不把它误报为所有联系区都深浅错乱。
4. 共享 Lightbox 在 `basic-view.tsx:29` 和后台预览 `template-preview-dialog.tsx:152` 已传入对应 tone。改材质时要覆盖公开页和当前编辑预览，但不得影响 Flow 与高级拍立得。

### C：十一套受影响界面复核

用同文字、同照片、同视口、同初始状态比较修改前后。主视口 1440×900／390×844，实际改动位置补 320 与 1280×720。逐套核对首屏→作品→套餐→联系→大图→关闭返回，以及手机操作栏。确认照片可见面积、标题与主操作没有退步，再报告完成度。

本轮的 C 是本报告的配色回归步骤，与历史 Flow S3 无关，不恢复已取消的 Flow 方案。
