## 2. 值得保留的设计与功能

1. **独立业务和清楚的发布语义。** 十一基础模板共用一个基础内容空间；拍立得和Flow各自独立，仅共享Site资源。Flow同时显示保存草稿v5、公开v4和尚未发布，桌面集中操作、手机固定“仅保存草稿／保存并发布”已形成完整能力。
2. **照片到展示的真实路径。** 图库已有上传限制、筛选、分页、元信息、逐项结果；分类有命名、选片顺序、整卡排序、撤销和说明，五模块能预览当前效果。不能再将这些写成缺失功能。
3. **有用途的视觉身份。** Flow的双轨、书法标题、半透明导航、分组作品和连续大图；拍立得的纸面、相框和夜空；基础十一种构图各自表达摄影作品。后台采用熟悉控件和浅灰绿层级是合理选择。

## 3. 前台 Experience 评审

Flow 有自己的观看路径：先速览、展开分类、看大图、连续浏览、返回，再读服务与联系。大图默认适屏，键盘与关闭返回已存在。问题不是缺少视觉特征，而是某些低高度画面中，分类标题与首图之间的等待较长，以及无说明照片缺乏可以听懂的区分信息。

B补验灯箱Tab／Shift+Tab循环及Escape后稳定返回原照片按钮有效；同步采样出现的BODY是过渡状态，未记作焦点缺陷。现有短价格卡的clientWidth与scrollWidth均为304px，不能据长文本源码风险声称当前价格已溢出。五后台在390／320／1280的整页宽均未超视口；本轮未完成全部照片背景的对比度合成测量，不宣称全面达到AA。

中文标题使用 `KaiTi / STKaiti / Kaiti SC / serif` 声明栈，正文为 `Arial / Microsoft YaHei / sans-serif`。书法标题属于已有批准方向，不能因检测器提示常用字体就换成通用落地页。具体系统fallback字形没有逐字核验，不把声明栈当成跨平台字形一致的证据。

匿名几何照片能检查位置、裁切和返回，不能评价真实摄影作品的色彩情绪。当前公开的一侧空轨是内容状态；本轮没有将其改填或切换比例。首页即时流动、暂停、轨道滚轮、减少动态稳定列表都有现有实现和CI证据；本轮没有完整重测每种输入设备。

## 4. 后台 Operate 评审

Flow五模块已经按操作对象组织，价格和联系的项目编辑已前移。手机的主要负担集中在进入后台之前和图库初始屏：当前公开空间的编辑入口在工作台第三张卡；进入图库后，状态、介绍、上传限制、数量、跳转和筛选继续占用首屏。导航最后一项被横向裁切，进一步增加第一次使用的寻找成本。

桌面补评确认信息占位同样影响照片任务：首图约y695.92，1280×720只露出约24.08px；第二分类的效果预览从整页顶部开始，目标约y1511.95，需要再次寻找。图库横幅筛选进入选片后恢复全部方向，重复一次筛选。1280嵌套分栏的照片说明区仅约242px宽，1920联系短字段却约1072px宽。前三项有现场路径证据，后两项是局部布局建议，详见[桌面五项发现](IMPECCABLE_DESKTOP_REVIEW.md#3-五个主要桌面发现)。

后台声明 `Segoe UI / Microsoft YaHei / sans-serif`，主标题局部使用宋体/衬线；熟悉系统字体不应因工具偏好被移除。辅助文字、表单密度可以分级收束，但草稿／公开双状态、异常恢复入口、可选二维码、实际资源归属都必须继续可见或可明确到达。不能把长说明简单堆进更高的固定头栏，也不能重新隐藏用户经常需要的字段。

## 5. 平台入口评审

受邀登录、稳定公开地址、三独立内容空间的表达诚实，工作台也能辨认当前公开空间。平台首页的作品布局示意较晚出现，使首屏比实际产品更通用。这是低优先级的表达选择，不是功能或安全阻断。应先解决已有用户如何更快进入正确编辑对象，再考虑将现有匿名示意前移；不新增宣传承诺或改变账号模型。

## 8. 推荐方案与局部备选

主推荐是保留浅灰绿后台和现有Flow前台，先完成S1a的共同信息收束与当前分类预览定位，再处理S1b的筛选衔接、局部栏宽、预览入口和手机导航。所有下述为文字方案，没有生成或修改页面原型。

手机后台文字线框：当前模块与五入口 → 一行草稿/公开摘要 → 当前对象标题与主操作 → 必要筛选 → 照片/当前项目 → 固定双保存按钮。上传限制贴近上传入口，低频诊断继续可展开；异常恢复保持清楚可达。桌面保留侧栏，不用更高固定栏吞掉回收的空间。

手机导航仅提供两种局部选择：

- **推荐：两行五入口。** 所有模块可发现；多占一行的高度必须由重复标题/说明/工具间距中回收，并以R2同数据测量确认净改善。
- **备选：当前模块＋原生分区选择器。** 占用更少，可清楚切换；其他模块需要一次展开。保留标签“切换模块”，不能只剩无文字图标。

不建议全站换肤、再增加大型状态面板、重新加入已移除的排序工具栏，或把高级后台强行映射到基础字段。
