# PR35 价格面板条带排查与选区配色

日期：2026-10-07。接续用户在价格页选中文字后悬停“联系方式”的截图反馈。仅修改 Flow 前台局部 CSS，保留大外框、原文、几何、内容和业务行为。

## 事实与待确认项

- 价格面板没有 `overflow` 滚动设置；滚动发生在外层 `.scene`。实测没有横向内容溢出，导航 hover 仅改变链接背景，不修改面板尺寸。截图中的宽横条及右侧深条不能当作普通滚动条处理。
- 橘色选区来自平台全局 `::selection` 的 `--acid: #ff6b00`，Flow 原先没有自己的覆盖。
- `.scene` 的 opacity 淡入使用 `animation-fill-mode: both`，价格面板声明 `backdrop-filter: blur(20px)`。在独立浏览器页取消祖先动画后，20px 模糊变得明显；说明原稳态下其视觉效果被祖先动画隔断。此实验会明显改变原透明材质，因此没有用于产品修改。
- 原版自动截图没有稳定复现用户截图中的宽条带。动画、滤镜与悬停重绘的交互是主要嫌疑；不能仅凭代码和修正版截图声称已经证实浏览器底层根因。

## 最小修正

- 仅关闭价格大面板的背景滤镜，保留42%透明底、白边、圆角、尺寸和原淡入。顶部导航与其他玻璃组件保持。
- Flow 根节点及后代的文字选区改为浅绿色背景、深色文字，并移除选中文字阴影；基础模板的全局选区不改。
- 没有隐藏真实滚动条，没有添加强制 GPU 层、遮罩、固定栏或滚动脚本。
