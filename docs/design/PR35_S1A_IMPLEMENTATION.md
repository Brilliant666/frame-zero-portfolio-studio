日期：2026-10-06。用户确认[主报告](IMPECCABLE_REVIEW.md)后的第一实施切片；原 Impeccable 手机、桌面评审及工具来源全部保留。实施仍在 PR35 独立工作区，基于评审 Head `2192d885647b88856dfe87f07c362eb17c908dc7`，不另建 PR。

## 实现范围

- 图库只保留一个任务标题，将数量、共享用途、上传限制与操作收束到同一面板；筛选紧接照片。上传展开、素材 ID、元信息、分页、重新读取和异常反馈保留。
- 照片尺寸、列数和间隔保持；桌面 180px、手机 160px 的照片容器未缩小。原固定发布栏和手机模块导航未改。
- 分类预览在每次打开时校验当前稳定 ID，使用真正的 Flow 前台渲染器，在全屏内定位并聚焦该分类标题。其他可展示分类与原顺序保留，提供“从头看完整作品”。普通浏览不会反复被拉回目标。
- 关闭或 Escape 恢复分类、编辑步骤、后台滚动和实际触发按钮焦点；快速重复打开只产生一个对话框，再打开重新定位当前对象。
- 隐藏、空、已失效分类明确反馈，不开启隐藏分类、不改成员。空与失效素材仅解释不可展示；仍由用户决定内容修改。

未修改数据库、内容 schema、权限、保存发布、成员排序与 Flow 前台视觉。未做常驻半宽预览；S1b 的手机导航、筛选衔接及栏宽整理，S2/S3 均未实施。
