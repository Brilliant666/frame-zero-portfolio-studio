# 平台首页与 Site 工作台：上线前 UI 候选

基线：main `c861ad64298e377480f5d44185e26cf5d316be53`（PR45 已合并）。
本轮只优化平台首页与 Site 工作台；不升级日常应用，不修改任何前台模板、权限规则、schema、草稿或 Published。

## 现场与原问题

先在正常登录状态观察既有 Site 工作台，核对当前公开空间为星轨，以及基础版、星轨、流影视廊三个已授权编辑入口。
会话失效后使用原受邀账号正常登录继续，只读查看，未操作保存、发布或上传。
公开主页继续显示原拍摄套餐与作品集；不将本轮当成十三套前台效果的验收。

- 原首页把文字英雄区、第二层介绍放在示意图之前，手机第一屏主要是说明文字。
- 原工作台把页面介绍、Site/账号、公开状态、三个重复功能卡片分成多层；手机其他空间入口很靠后。
- 首页仍推广内部测试入口；本轮从公开首页 HTML 中移除这些链接，不依靠 CSS 隐藏，也不改既有路由门禁。

## 实施

首页使用留白纸面、深墨色产品展示区和胶片/版面构图，把公开模板图前移到首屏。
仅复用已审查的 `film-rail`、`editorial-duet`、`cinematic-light` 布局图，并为星轨/流影视廊绘制原创 CSS 结构示意；明确标注为布局示意，不含客户照片。
登录主操作、受邀说明与不开放公众注册保留；三空间各自编辑、共用本站图库、单一公开主页的关系缩短说明。
首页专用 modifier 隔离新样式，登录页原布局保持。

工作台按 Site/账号 → 当前公开状态及编辑草稿 → 三个紧凑空间入口 → 折叠帮助组织。
当前公开空间用明确的主编辑操作；发布快照版本降为次要信息，明确不代表当前草稿。
未授权空间只显示状态；公开授权复核不通过时，主面板与该空间行都不渲染编辑链接。
身份查询、`publishedDraftTarget`、publicationHistory、公开读取和保存发布链路保持。

首页同一公开路由、相同视口对照；工作台旧版为真实已登录 Site，新版为同授权和公开状态的匿名渲染样本，Site 名长度不同，不能当作同账号端到端数据。

## 状态、隔离与测试

匿名候选在单一 loopback 端口展示真正 Next 生产首页，以及生产 `renderSiteWorkspace` / `siteEntryPage` 渲染的状态页。
包含：三个空间分别已发布、未发布、读取失败、高级未授权、当前空间授权撤销、无可编辑空间。
浏览器逐项核对公开状态、编辑 href、不可用提示及公开主页路径；unknown 没有被展示成未发布。
所有样本均独立创建，不连接数据库，不加载账户配置，禁止业务写请求和私人资源/API路径，向 Next 转发前去掉 Cookie/Authorization。
隔离说明置于正常文档流，避免覆盖主要操作。登录/编辑/公开主页落点仅给无写入说明，不冒充真实编辑器。

250项 `test:admin` 通过，包含21项新增回归；最终相关31项复核通过，两组有重叠，不累加。
新增用例覆盖实际首页 React SSR、生产工作台渲染、授权/撤销/未知状态、escaping、私有缓存头，以及真实 loopback HTTP 隔离边界。
旧测试仅把被合并的说明文案断言改成“发布快照只读／非当前草稿／保存不改变公开”语义，原授权与目的路由断言保留。
局部 eslint、独立 TypeScript 与最终生产构建通过。新增回归接入 `test:admin`，不是孤儿测试。
构建体积检查保留跨路由CSS告警：437,910→448,639 bytes（增加10,729 bytes），阈值与断言未改。
首页静态入口CSS估算为73,662→84,391 bytes，JS估算保持575,957 bytes；均为原始产物估算，不是gzip传输或浏览器耗时。
最终 Head 的五项 CI 以新 Draft PR 的真实检查为准；不引用 PR45 的成功代替本轮检查。

## 候选与人工确认

在候选工作区使用 Node24：`node tests/launch-ui-review-server.mjs --port 3004`。
首页：`http://127.0.0.1:3004/`；工作台：`http://127.0.0.1:3004/__review/workspace?state=published`。
状态名另有 `basic`、`flow`、`unpublished`、`unknown`、`ungranted`、`revoked`、`basic-none`。
复用既有闲置工作区、依赖及构建位置；不复制 node_modules、数据库、图库或 release。精确本机路径和进程只记私有交接。

这是待人工视觉确认的候选，不以构建成功宣称已达到正式上线品质。
当前布局示意是否有足够摄影辨识度、主视觉墨绿与工作台蓝灰的搭配，仍需用户确认；没有授权客户照片被用于宣传。
新版工作台未在日常真实账号上部署，不能冒充真实数据库/会话的新版端到端验收；实体手机未专项测试。
既有 `PREVIEW_RETURN = UNRESOLVED` / `RISK_DISPOSITION = ACCEPTED_FOR_LOCAL_STAGE` 保持，不作为这两个页面的新缺陷。
只创建 Draft PR，等待视觉验收；不合并、不部署或自动进入下一阶段。
