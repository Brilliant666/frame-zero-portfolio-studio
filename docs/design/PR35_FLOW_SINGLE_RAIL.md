# Flow 首页自动单轨（2026-10-07）

用户确认单侧未选择时展示已有作品，并授权实施。延续 PR35 Draft，只调整首页作品区的呈现；3004提供候选，3001保持原版。

## 行为

- 两侧都有有效照片：保持已保存的双轨比例与左右方向，包括两侧选择同一分类的情况。
- 只有一侧有效：在原作品区居中显示单轨，桌面宽度上限500px，手机上限300px；右侧单轨仍反向流动。
- 两侧都无有效照片：显示“还没有作品”。显式未选、分类失效或照片无法解析均不会自动补入其他分类。
- 匿名设计预览未配置轨道时，继续取前两个有效分类。正式内容的空选择保持为空。

布局判断使用已授权解析的展示内容。只改变显示投影，不写入轨道ID或比例；另一侧恢复有效照片后，自动返回原双轨比例。照片比例、竖图高度限制、成员顺序、灯箱分类范围、滚轮/悬停、暂停、键盘与减少动态模式保持。单轨图片在测量前使用对应500/300px响应式提示，测量后继续使用实际图片槽位。

## 验证

23项相关纯测试、局部ESLint、TypeScript与独立普通构建通过。新增投影矩阵覆盖左右独轨、双空、空/失效分类、同分类双轨、默认与保存比例、原照片范围和内容不变。

浏览器CI新增内存预览矩阵：1440、390、320、700、701px，验证左独轨、右独轨及双空，居中/上限/实际sizes保留1px容差；恢复原选择与视口后继续已有双轨比例、流动、DPR2和发布隔离断言。该矩阵使用减少动态模式，只验证右侧方向类；实际双轨动效由原专项验证，不能声称矩阵直接测出右独轨运动方向。最终CI按当前Head另行记录，不用历史成功替代。

现场3004复核1440/390/320均无横向溢出，sizes与图片clientWidth一致。悬停出现zoom-in并暂停，滚轮200px使轨道位移200px，仍在works；显式暂停改为原生滚动列表。大图使用full变体，范围1/2，Escape关闭恢复原照片焦点。候选前后六业务表摘要一致，原应用构建保留，可仅恢复应用。
