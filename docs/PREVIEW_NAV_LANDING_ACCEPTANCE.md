# Preview 顶栏与封面落地时序验收

本轮只修改 `/preview` 的两项表现：封面飞行期间隐藏落点、按最新 `star-motion-demo.html` 重做顶栏。参考文件只读，原版首页、后台、数据契约及主题内容均不调整。

## 1. 封面落点

- **通过**：有效飞行开始前，对落点整张卡片设置 `visibility:hidden`，其星钉与胶带一并隐藏。
- **通过**：飞行完成回调中直接恢复原 visibility，落点照片不增加 opacity、filter 或位移动画；星钉弹出，替身在上方淡出 180ms。
- **通过**：取消进场、中途切换减少动态效果会恢复落点；无效/屏幕外落点不进入隐藏流程。
- 浏览器在 0–1.2 秒录得 146 帧，选取每 50ms 一张的 25 张真实截图；采样与目标时刻偏差最多约 10.67ms。飞行替身最多一个，落点约 47ms 起隐藏、1067ms 落地恢复，落点自身没有动画。

## 2. 顶栏

- 桌面高度 68px，主题背景渐隐层，无整条毛玻璃底或下边线；品牌为星标和 profile 摄影师名，思源宋体 Heavy 22px。
- 主导航与构图切换共用 `GlassSegments`，全圆角、主题边线和玻璃底，选中指示器移动 500ms；保留真实链接、aria-current 与构图按钮 aria-pressed 语义。
- 主题按钮 40px；支持 View Transitions 时从按钮中心圆形展开 700ms，不支持或减少动态效果时直接切换。
- 手机品牌与主题按钮第一行，三等分满宽导航第二行；图集标题卡和构图切换在顶栏下面，使用相同水平边距。
- 接口注入只在 development / 本机 preview 构建生效；普通模板继续使用原导航，新增 CSS 以 preview 主题标记限定范围。
- **通过**：最终 16 张代表截图没有横向溢出。主题切换前后顶栏、导航、首页按钮的矩形最大变化为 0px。桌面顶栏实测 68px，手机导航距两侧 16px、宽 358px。
- **通过**：键盘导航有 2px 主题焦点框；夜空下选中且悬停的导航继续使用深色 on-accent 文字，不被 hover 覆盖。
- **通过**：主题动画实测 duration 700ms；额外保存 350ms 时间半程及约半径一半的 105ms 画面，避免缓出曲线的时间半程看起来接近完成。
- **通过**：手机三个导航项实测各 116px。品牌 CSS 为 22px / 900，Chrome CDP 确认四个汉字由自托管 Noto Serif SC 字体绘制（`brand-font.json`）。
- **通过**：原版 `/` 同一本机正式运行方式前后截图尺寸一致；1440 / 390 宽度像素差分别为 0.0966% / 0.1691%，全部位于原有持续横向滚动字幕区域，其余像素完全一致，不把动画相位差误报为静态外观变更。
