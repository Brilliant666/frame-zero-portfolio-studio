# PR34：图片、条件缓存、旧写接口与分享信息

更新：2026-10-01。用户已授权修复核实后的四个切片；在现有 Draft PR34 开发工作区实施。

## 1. 图片按展示位置选择变体，公开素材支持条件缓存

流影视廊不再把每张轨道照片固定解析为 `full`。默认 URL 使用 `card`，同时提供 thumbnail/card/full 的 `srcSet`，宽度描述符取实际变体像素宽度。轨道按实际栏宽填写 `sizes`，保留不同轨道比例、手机和嵌入式预览；完整作品按实际网格宽度选择资源，离屏照片延迟加载。全屏背景按 cover 所需尺寸选择，大图打开时使用 full 展示变体，不读取 original。

照片内在宽高、成员顺序、封面、轨道动画、滚轮、暂停、键盘与大图返回逻辑保留。匿名设计 proof 仍支持单一自制图片 URL。

公开素材改为 `private, no-cache, must-revalidate`，以文件字节 SHA-256 生成强 ETag。每次请求都先核对平台请求边界、当前 Published 引用白名单、Site 归属、允许的展示变体及文件可读性，再判断 `If-None-Match`。匹配返回空体 304；不匹配返回当前图片。GET/HEAD 一致，Range 仍拒绝。私人素材仍 no-store。

不使用一年 immutable 缓存：Published 撤下引用后，旧 ETag 也必须收到 404；文件缺失不能误回 304。浏览器可复用已缓存字节，服务端仍读取文件与核对授权。该改动减少网络传输，不宣称消除了服务端文件读取开销。

审查者提供的 28 张素材 full/card 合计差异为 4,806,914 字节（约 4.58 MiB）。这是候选变体字节差异，不是本轮现场网络节省量；实际选择受照片比例、栏宽、DPR、背景及已缓存资源影响。

## 2. 停用旧全局 D1 写接口

`/api/site-content` 的 PUT 固定返回 `410 LEGACY_WRITE_DISABLED`，在读取请求体、初始化 D1 或创建表之前拒绝。删除按 URL 回环地址及 ChatGPT 身份头授权的路径，不新增调试写开关。

GET 保留旧内容读取及原有兼容逻辑。旧全局 `/admin` 的保存动作会显示“旧版全局内容写入已停用，请使用本站后台保存”。当前 `/:siteSlug/admin` 的基础、高级拍立得和流影视廊使用 Site 范围接口，保存草稿、保存并发布及版本冲突逻辑保持。

拒绝测试包含回环 URL、伪造 Host/Forwarded、身份头、错误 JSON、超大正文，均断言没有 D1 调用或源内容变化。旧正向写测试改为真实存储内容的 GET 兼容读取测试。

## 3. Published 品牌标题与分享元信息

流影视廊浏览器标题及 og/twitter 标题使用 Published 的 `profile.brand`；首页栏目大标题仍使用 `profile.title`。基础与拍立得保留各自现有标题规则。

分享信息的站名、URL、介绍均属于当前 Site 的 Published。图片选自已解析资源与 Published 白名单的交集：流影视廊优先背景，其次可见作品；基础取启用作品，拍立得取可见图集封面或成员。只使用当前 Site 公开 `card` 路由。无有效照片就不声明分享图。未发布站点清空旧全局分享信息。

绝对 URL 取验证后的平台配置 origin，不取 Host 或 Forwarded。没有新增品牌字段、分享卡上传或图片生成服务，也不暴露私人 `public/og.png`。

## 4. 高级真实路由计量

沿用既有软预算政策，不把三项聚合体积参考擅自升级为硬门禁；资源缺失、路径越界、懒加载完整性、单模板 64 KiB 限制仍阻断。现有五个 workflow 已监听 pull_request；HTTP 集成已由 accounts 测试调用，无需重复添加。

在已有匿名 Flow UX 隔离回归中增加第 7 场景，测量流影视廊公开页和专属后台，桌面 1440×900、手机 390×844，各自 cold/warm。第8场景以独立匿名DPR2桌面context核对较大变体选择。使用没有 Playwright route 拦截的新 context，保持真实 HTTP 缓存；后台会话只在内存复用，不写入证据。计量仅访问该隔离 origin 的 GET/HEAD。

报告分别记录 JavaScript、CSS、image 请求数、Resource Timing 的 transfer/encoded/decoded 字节及 CDP 缓存标志/原始304状态；不凭传输量大小猜测缓存命中。缺测保持 null 与 NOT_MEASURED/PARTIAL，不编造零。该结果属于初始路由已加载资源，不等于整图库、大图浏览、所有模板、真实客户或公网性能验收。

构建检查仍报告自己的静态原始字节；不能把匿名浏览器传输量填入它的静态指标。当前构建跨路由 CSS 为 318,209 字节，比 307,200 字节软参考高 11,009；本次没有新增 CSS，保持明确警告，不做预算压缩。
