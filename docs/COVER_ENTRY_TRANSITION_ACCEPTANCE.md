## 复现与修复

- 已复现：封面为 anon-1、重点照片为 anon-7 时，旧实现飞向 anon-7；落点同时执行 opacity 0 → 1 与强显影。
- 默认主角：封面 → 重点照片 → 第一张；显式本机选择仍优先。下拉默认项为“封面（默认）”，使用 v2 存储，不读取旧 v1。
- 飞行按封面 assetId 定位，封面不完整可见时退化为普通钉入；不以其他卡片替代。
- 落点卡不淡入、不显影；飞行副本使用目标卡的实际相纸、照片区域与裁切，落地后 180ms 淡出。
- 其余照片保持不透明，显影为 brightness(1.2) saturate(.6)，持续 1200ms；减少动态效果直接显示。
