# 图集整卡拖动

2026-09-29，按用户确认的简化方案实施。此决定替代旧精确排序工作区中的批量选择和输入序号入口；基础内容、图集成员管理和保存发布契约不变。

- 照片排序仅保留照片卡片、序号与角落放大按钮，整张卡片可拖动。排序模式不再渲染工具栏、勾选框或独立手柄。
- 桌面移动超过5px进入拖动，显示跟随照片及前后插入线；松手更新内存顺序。拖出列表、Escape、失焦或取消不提交移动。
- 触屏长按350ms进入拖动；此前滑动超过8px交还正常滚动。长按后使用非被动touchmove监听阻止原生滚动，拖近屏幕上下边缘自动滚动。
- 卡片可聚焦，方向键/Home/End继续排序；放大按钮独立操作。移动后显示12秒撤销入口，外部图集变化后不会用撤销覆盖新编辑。
- 图集设置中的封面选择、批量移出保留；更新效果不自动保存或发布。
