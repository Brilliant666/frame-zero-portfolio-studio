# 图库到图集的创建流程

2026-09-29，按用户确认的顺序调整高级后台：图库 → 图集 → 主页资料 → 拍摄套餐 → 联系约拍。无 hash 时默认打开图库，既有分区链接继续有效。

- 图库负责上传和浏览本站照片；基础与高级共用资源，各自内容仍独立。上传旁提供进入图集的入口。
- 图集列表明确显示“几个图集”，每张封面卡显示成员照片数，避免把封面数理解成照片数。
- 新建先填写名称，空白名称不可确认；取消不创建空图集。确认后才创建内存图集并自动打开该图集的选片窗口，不再选择目标图集。
- 加入后回到原排序工作区，提供确认封面、查看效果的连续入口。效果页面提示使用既有保存并发布操作；未增加任何自动保存或发布。
- 命名和选片使用模态键盘边界，保存快捷键不会穿过命名框；关闭选片返回当前图集选片入口。

已有图集仍可直接编辑。图库批量加入已有图集的辅助能力保留；本次不改上传底层、服务端、数据模型、迁移、基础业务内容和公开展示样式。
