# PR34 流影视廊后台设计候选

更新：2026-10-01。用户确认“将此版转为流影视廊候选，拍立得另做专属设计”。本切片是匿名可操作候选，等待视觉确认后再接入真实业务。

## 当前交付

- 图库：本地图片读取、名称及方向筛选、按点击顺序多选、加入已有分类或命名后新建分类并选片。
- 作品分类：整卡拖动、手机长按、键盘排序及撤销；分类名称、显示状态、逐张说明、移出及撤销。
- 展示效果：使用现有真实 `SiteFlowGalleryView` 查看当前分类的完整作品和大图，直接反映顺序及说明。
- 首页速览：品牌、标题、介绍、背景及焦点；左右轨道引用分类，保留原 2∶1，支持 7∶3、5∶5、左轨 30%–70%。直接查看真实首页效果。
- 全局操作：草稿与公开双状态、桌面集中操作、手机固定双按钮；模拟失败保留编辑和公开快照，可重试。普通焦点切换不再改变底部栏布局，软键盘处理依据 visualViewport。

建议体验路径：图库 → 多选 → 新建作品分类 → 确认选片 → 照片顺序 → 分类与说明 → 查看当前分类效果 → 首页速览 → 查看首页效果 → 模拟保存并发布。

Flow 数据仅包含现有 Flow 字段。分类首张照片用于后台列表缩略示意，不新增业务封面。共享排序器使用局部 Collection 适配，纸面、封面及星座字段不进入 Flow 快照；适配器保留排序结果引用，使现有撤销保护有效。拍立得另做专属视觉及业务组织，不沿用本候选。

## 候选边界

- 路径 `/preview/admin-design`，使用独立 loopback proof 构建、签名运行器和 `FRAME_ZERO_ADMIN_DESIGN_PROOF=1`。普通构建保持关闭。
- 图片是已有自行生成的虚构人物素材，3 张分别重复用于 18 张及 48 张操作验证。没有原站素材、私人照片、热链或跟踪地址。重复素材只用于交互验证，不能作为真实作品丰富度的证明。
- 添加图片只创建浏览器 object URL，不向服务端上传。所有编辑、草稿及公开状态只在当前页面内存；刷新清除。候选页面明确提示此限制。
- 不请求业务 API，不接入账号、Site 授权、正式上传、草稿持久化或真实发布。真实价格、活动和联系模块不在此样板中；不是已完成整个高级后台。
- 3001、现有数据库、草稿和 Published 不改变。3006 是独立候选；旧构建和失败证据保留。
- PR34 仍 Draft，不合并、不部署；本轮候选留在工作区，未提交或推送。视觉确认后再确定真实接入范围。

## 运行与回归

使用 Node >=22.13，先 `npm run build:preview:local`，然后在独立终端配置候选 flag，运行 `npm run start:preview:local -- --port 3006`。可指定 `FRAME_ZERO_ADMIN_DESIGN_ASSET_ROOT` 为本机匿名 WebP 文件目录；没有配置则显示自行实现的几何占位图。素材不进入仓库。

纯测试：`npm run test:admin-design`；浏览器：配置 `ADMIN_DESIGN_ORIGIN=http://127.0.0.1:3006`、仓库外 `ADMIN_DESIGN_EVIDENCE_DIR`，然后 `npm run test:admin-design:browser`。本机使用已安装 Chrome 时配置 `FRAME_ZERO_BROWSER_CHANNEL=chrome`。测试不启动服务、不创建账号或数据库。

本机具体启动、停止、日志、构建 ID 和截图位置记录在约定私有运维目录的本切片 RUNBOOK；不把本机路径、凭据或照片提交到公共仓库。
